# 토익 900 복습 (PWA)

Notion 「규짱의 토익 900점 프로젝트｜8주 기출 학습」 계획서를 그대로 옮긴 복습용 웹앱입니다.
빌드 과정 없이 정적 파일만으로 동작하고, 휴대폰 홈 화면에 설치하면 앱처럼 오프라인에서도 쓸 수 있어요.

## 기능

| 탭 | 내용 |
| --- | --- |
| **오늘** | 시작일 기준 N주차 진도(기출·핵심 목표·보카 DAY), 요일별 스케줄, 오늘 복습할 단어·오답 수, 매일 체크리스트, 학교 시험 주간 모드(하루 45분으로 축소), 복습 밀림 경고 |
| **단어** | 뜻을 가리고 떠올리는 플래시카드. **당일 → 다음 날 → 3일 뒤 → 7일 뒤 → 14일 뒤** 간격 반복. 실제 어원과 개인 연상 장면을 따로 기록, 결합 표현, 🔊 발음 듣기, 여러 단어 한 번에 추가(`단어 \| 뜻 \| 결합 표현`), **📷 사진·손글씨로 틀린 단어 추가**(아래 참고), 두 번 이상 틀린 단어에 "연상 메모 필요" 표시, 헷갈린 단어 필터(7주차 재학습용) |
| **오답** | 회차·Part·문항, 오답/찍어서 맞힘/헷갈림, 원인 5분류(단어·문장 구조·소리 인식·근거 오해·시간 부족), Part 5 유형(구조·문법/의미·어휘), Part 7 오답 이유(대상·날짜·조건 불일치·근거 없음), 판단 기준·정답 근거·바꿔 표현. **다음 날 재확인 → 일주일 뒤 반복 실수 점검** 자동 일정, LC는 6단계 복습 체크리스트 |
| **회차** | TEST 1~10 기록(Notion DB와 같은 항목: 날짜·상태·LC/RC 정답 수·RC 미완료·재확인 여부·주요 오답 원인·바꿀 행동) + 파트별 소요 시간, 회차별 원인 분석과 진단에 따른 조정 제안 |
| **더보기** | 실전 타이머(LC 45 / P5 12 / P6 8 / P7 55 / RC 75분, 초과 시간 표시, 회차 기록에 저장), 주간 점검(이번 주 자동 요약 + 계획서 양식), 설정, JSON 백업/복원, 단어장 CSV 내보내기 |

## 📷 사진·손글씨로 틀린 단어 추가

### ✍️ 손글씨: 폰의 글자 인식 + 붙여넣기 (무료)

1. **iPhone**: 카메라·사진 앱에서 글자 인식(라이브 텍스트) 버튼 → 전체 선택 → 복사
   **갤럭시·안드로이드**: 카메라·갤러리의 텍스트 추출(T) 또는 Google 렌즈 → 텍스트 → 복사
2. 단어 → 추가 → 붙여넣기 칸에 넣고(또는 **📋 붙여넣기**) **목록 만들기**
3. 결과를 확인·수정하고 추가

`단어 뜻`, `단어 - 뜻`, `단어 : 뜻`, 한 줄에 여러 쌍, 뜻을 다음 줄에 쓴 노트 모두 알아봐요.

### 📷 인쇄된 글자: 사진으로 바로

단어 → 추가 → **사진 찍기 / 고르기**. 단어장·단어 시험지·기출 해설을 찍으면 영어 단어와 한국어 뜻을 읽어 후보 목록으로 보여줘요.

- 사진은 서버로 보내지 않고 **폰 안에서** 인식해요 ([Tesseract.js](https://github.com/naptha/tesseract.js), 무료).
- 처음 한 번은 인식 엔진·언어 데이터(약 5MB)를 내려받느라 인터넷이 필요하고 시간이 조금 걸려요.
- `영어 [발음] 한국어 뜻` 줄은 단어·뜻을 짝지어 주고, 영어만 있는 줄은 단어별로 나눠요.
- 결과는 고치거나 체크를 풀어 뺄 수 있어요. "틀린 단어로 표시"를 켜 두면 헷갈린 단어 목록에 들어가고, 이미 있는 단어는 중복 추가 대신 틀림 처리돼 오늘 다시 복습해요.
- 펜 표시(동그라미·체크)와 손글씨는 잘 못 읽어요. 손글씨는 위의 붙여넣기 방법을 쓰세요.

## 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 휴대폰에서 쓰기 (GitHub Pages)

> github.com 저장소 주소나 파일(raw) 주소로는 코드만 보이고 앱이 실행되지 않아요. 아래처럼 Pages를 한 번 켜야 앱 주소가 생깁니다.

1. PC 또는 모바일 브라우저에서 https://github.com/gyu2754-netizen/-/settings/pages 접속
2. **Build and deployment → Source: Deploy from a branch**
3. **Branch: `claude/toeic-review-app-3j0y1j`**, 폴더 **`/ (root)`** 선택 → **Save**
4. 1~2분 뒤 같은 페이지 위쪽에 뜨는 주소로 접속: **https://gyu2754-netizen.github.io/-/** (끝의 `/` 포함)
5. iPhone Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치

앱이 빈 화면이면 화면에 오류 메시지가 표시되니 그 내용을 알려주세요.

## 데이터

- 모든 기록은 **그 기기 브라우저(localStorage)** 에만 저장됩니다. 서버로 전송되지 않아요.
- 기기를 바꾸거나 브라우저 데이터를 지우기 전에 **더보기 → 설정·백업 → 내보내기**로 백업하세요.

## 구조

```
index.html            화면 틀, 하단 탭
css/style.css         스타일 (다크 모드 지원)
js/ocr.js             사진 단어 인식
js/data.js            계획서 내용 (진도표, 요일 스케줄, 원인 분류, 복습 간격 등)
js/app.js             화면·저장·복습 일정 로직
sw.js                 오프라인 캐시
manifest.webmanifest  홈 화면 설치 정보
```

계획을 바꾸려면 `js/data.js`만 고치면 됩니다 (예: `WORD_GAPS`로 단어 복습 간격, `SCHEDULE`로 요일 스케줄).
